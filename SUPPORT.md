# Hilfe und Support / Help and support

Industrial Kiosk Browser ist kostenlos und Open Source. Für Hilfe gibt es zwei Wege.
Industrial Kiosk Browser is free and open source. There are two ways to get help.

## Kostenlos: GitHub / Free: GitHub

- **Fehler und Wünsche:** [Issue anlegen](https://github.com/ict-baden/industrialkioskbrowser/issues/new/choose)
- **Fragen / questions:** ebenfalls als [Issue](https://github.com/ict-baden/industrialkioskbrowser/issues/new/choose) – also as an issue

Wir lesen alles, können aber keine Reaktionszeit zusagen. Alles dort ist öffentlich – bitte keine internen Daten.
We read everything but cannot promise response times. Everything there is public.

## Verbindlich: Supportvertrag / Guaranteed: support contract

Mit einem Supportvertrag von ICT-Baden bekommen Sie:

- zugesicherte Reaktionszeiten
- Hilfe bei Einrichtung, Verteilung und Betrieb in Ihrer Umgebung, per E-Mail, Telefon oder Fernsitzung
- vertrauliche Fehleranalyse (mit Auftragsverarbeitungsvertrag)
- Vorrang bei Fehlerbehebungen und Sicherheitsinformationen vorab
- Anpassungen und Schulungen nach Absprache

Kontakt: [Impressum](https://ict-baden.de/impressum/)

## Konfiguration mitschicken / Send your configuration

*Einstellungen → Configuration → Export to file* speichert die Konfiguration als JSON (ohne Klartext-Passwort, nur der Hash). Das beschleunigt jede Anfrage.
*Settings → Configuration → Export to file* saves the configuration as JSON (no plain-text password).
