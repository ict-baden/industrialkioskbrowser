Industrial Kiosk Browser runs your web apps on rugged Android devices – warehouse, production, logistics. Scans go straight into the web form, the device can be limited to the web apps you allow, and the whole configuration comes from your MDM.

BARCODE SCANNING
• Works with Zebra DataWedge, Honeywell scanners and any scanner app that sends an intent
• The scan is typed into the focused field like a keyboard, including Tab or Enter
• Web pages can also receive scans as a JavaScript event and control scanning per page

PROFILES
• Several web apps on one device, each with its own start address, allowed hosts, colors and settings
• One tap on the start screen opens the web app, or it starts automatically

KIOSK MODE
• Hide the toolbar and system bars, hide or password-protect the exit
• Allow list per profile: only those hosts can be opened, everything else is blocked before it loads (without a list every host is allowed)
• Lock task mode when the device is managed

CENTRAL CONFIGURATION
• Managed configuration from your MDM (for example SOTI MobiControl, Microsoft Intune, Workspace ONE)
• Configuration file, broadcast intent (StageNow) or QR code
• Settings on the device can be protected by an admin password

FOR WEB APPS
• Add your own CSS, JavaScript or HTML to third-party web apps, matched by address
• Hardware key remapping, hotkeys and macros such as {F1} or {TAB}
• Clear error pages with error codes, in your brand color

YOUR DESIGN
• Your title, logo and brand color, set by configuration or right in the app

PRIVACY
• No account, no ads, no tracking. Industrial Kiosk Browser sends no data to ICT-Baden.
• The app itself only connects to the web apps you configure and the pages they lead to.

User interface in English, German, Spanish, French and Chinese. Free and open source (MIT licence), made by ICT-Baden. Paid support contracts are available.
