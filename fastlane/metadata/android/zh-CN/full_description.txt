EnterpriseBrowser 让您的 Web 应用运行在加固型 Android 设备上，适用于仓库、生产和物流场景。扫描结果直接填入网页表单，设备只能访问您允许的应用，全部配置均可通过 MDM 下发。

条码扫描
• 支持 Zebra DataWedge、Honeywell 扫描器以及任何通过 Intent 发送结果的扫描应用
• 扫描内容像键盘输入一样写入当前焦点字段，可附加 Tab 或回车
• 网页也可以通过 JavaScript 事件接收扫描结果，并按页面控制扫描

配置文件
• 一台设备上可运行多个 Web 应用，每个都有独立的起始地址、允许的主机、颜色和设置
• 在主屏幕上轻点即可打开 Web 应用，也可设置为自动启动

Kiosk 模式
• 隐藏工具栏和系统栏，隐藏退出按钮或用密码保护
• 只能打开允许的主机，其他地址在加载前即被拦截
• 在受管理设备上支持锁定任务模式

集中配置
• 通过 MDM 下发托管配置（例如 SOTI MobiControl、Microsoft Intune、Workspace ONE）
• 支持配置文件、广播 Intent（StageNow）或二维码
• 设备上的设置受管理员密码保护

面向 Web 应用
• 按地址向第三方 Web 应用注入自定义 CSS、JavaScript 或 HTML
• 硬件按键重映射、快捷键以及 {F1}、{TAB} 等宏
• 清晰的错误页面，带错误代码，使用您的品牌颜色

您的设计
• 自定义标题、徽标和品牌颜色，可通过配置或直接在应用中设置

隐私
• 无需账户，无广告，无跟踪。EnterpriseBrowser 不会向 ICT-Baden 发送任何数据。
• 应用只连接您配置的网址。

界面支持英语、德语、西班牙语、法语和中文。免费开源（MIT 许可证），由 ICT-Baden 开发。可提供付费支持合同。
