# Sicherheit / Security

## Schwachstelle melden / Reporting a vulnerability

Bitte **kein öffentliches Issue**. Melden Sie Sicherheitslücken vertraulich:

- über GitHub: [Private vulnerability report](https://github.com/ict-baden/industrialkioskbrowser/security/advisories/new)
- per E-Mail an [security@ict-baden.de](mailto:security@ict-baden.de) (Policy: https://ict-baden.de/sicherheit/)

Please **do not open a public issue**. Report vulnerabilities privately via the link above or by email to [security@ict-baden.de](mailto:security@ict-baden.de) (policy: https://ict-baden.de/en/security/).

Hilfreich sind: betroffene Version, Schritte zum Nachstellen, mögliche Auswirkung.

## Was Sie erwarten können / What to expect

| Schritt | Frist |
|---|---|
| Eingangsbestätigung / Acknowledgement | 3 Werktage / business days |
| Einschätzung / Assessment | 10 Werktage / business days |
| Behebung / Fix | so schnell wie möglich, abhängig von der Schwere / as soon as possible, depending on severity |

Wir veröffentlichen behobene Schwachstellen als GitHub Security Advisory und nennen Sie auf Wunsch als Finder.

## Unterstützte Versionen / Supported versions

Sicherheitsupdates gibt es für die **neueste veröffentlichte Version**; Kunden mit Supportvertrag zusätzlich für die vorherige Hauptversion bis zwölf Monate nach Erscheinen der Nachfolgerin. Kunden mit Supportvertrag erhalten Sicherheitsinformationen vorab.

Security fixes are provided for the **latest released version**; customers with a support contract also receive them for the previous major version until twelve months after its successor appears.
